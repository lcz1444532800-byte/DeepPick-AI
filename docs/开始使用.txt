DeepPick AI 1.2.3 · Windows 64 位分享版
Developer:Chunze Liu

首次使用
1. 在压缩包上点右键 → 全部解压，目标选 D:\。
2. 确认程序位于 D:\DeepPickAI\DeepPickAI.exe。
3. 双击 DeepPickAI.exe。不要在压缩包内直接运行，不要只取出一个 EXE。
4. 按 Ctrl + Space，拖动框选，等待识别后拖动选字，Ctrl + Enter 复制。

本地识别免费、离线可用。软件已包含所需组件，不用安装 Python 或下载模型。
AI 增强可选：设置 → DeepSeek → 输入自己的 API Key → 测试连接 → 保存。
自动增强默认开启，未填 Key 时只运行本地 OCR；手动 AI 增强不受自动开关影响。

详细教程与常见问题：双击同目录“使用说明.html”，也可在首页打开。
桌面快捷方式：右键 DeepPickAI.exe → 显示更多选项 → 发送到 → 桌面快捷方式。
关闭首页后仍在后台运行；彻底退出：右键托盘图标 → 退出。

适用 Windows 10/11 x64，需要 D 盘，建议至少 1 GB 可用磁盘和 2 GB 可用内存。
开机自启默认开启，可在设置 → 常规关闭。
程序数据保存在 D 盘；仅开机启动快捷方式使用 Windows 实际启动文件夹。

不要把使用后的整个安装文件夹直接转发给别人，其中可能含你的密钥配置和历史。
请转发原始“分享版.zip”。
