1. 第一次使用

适用 Windows 10 / 11 的 64 位电脑。当前版本需要 D 盘；建议预留至少 1 GB 磁盘空间和 2 GB 可用内存。ARM 原生版本和 32 位 Windows 暂不提供。

  1. 下载原始的 DeepPickAI-1.2.3-Windows-x64-分享版.zip。
  2. 右键压缩包 → 全部解压，将解压目标设为 D:\。压缩包自带 DeepPickAI 文件夹，不要再多套一层同名文件夹。
  3. 找到 D:\DeepPickAI\DeepPickAI.exe，双击启动。首页应直接显示；第一次打开会在后台准备离线识别。
  4. 不需要安装 Python、配置环境、下载模型或填写密钥。直接按下一节完成首次识别。

不要在压缩包内直接双击程序，也不要单独取出 EXE。必须完整保留 app、models、DeepPickAI._pth 和根目录的 DLL。

创建桌面入口：右键 DeepPickAI.exe → Windows 11 的“显示更多选项” → 发送到 → 桌面快捷方式。Windows 10 可直接找到“发送到”。桌面入口由你手动创建，程序默认只创建开机启动入口。

2. 框选、选字、复制

  1. 按 Ctrl + Space，或在首页点 开始截图。
  2. 按住鼠标左键，拖出需要识别的区域，然后松开。红色十字光标在浅色背景上也可见。
  3. 识别中：选区保留原画面，覆盖半透明点阵动画；选区旁的工具栏显示状态。
  4. 识别完成：识别出的文字区域保持明亮，其他区域变暗。程序保留截图原字形；没有重新画一套文字覆盖在原图上。
  5. 在文字上按住左键拖动，所选文字变成黄色高亮。松开后可以继续拖动追加另一段，不需要按 Shift。
  6. 按 Ctrl + Enter，把已选文字复制到 Windows 剪贴板，选区随后关闭。在聊天框、文档或其他软件中按 Ctrl + V 粘贴。

复制采用合理的阅读顺序处理换行和空格；复杂多栏、合并单元格或公式建议先打开“查看文字”核对。

工具栏的查看文字可打开文本结果，支持直接修改、复制全部和导出文本。导出文件保存在 D:\DeepPickAI\output，不会被自动清理。

选区显示的是截图时的画面。需要操作背后的软件时，先按 Esc 或右键关闭选区。

4. 配置 DeepSeek AI（可选）

本地识别免费，离线可用。AI 增强需要联网，并使用你自己的 DeepSeek API 账户额度。普通聊天账号与 API 额度可能不同，费用以 DeepSeek 控制台和官方定价为准。

  1. 打开 DeepSeek API 控制台，登录后创建自己的 API Key。
  2. 如需调用 AI，在控制台确认 API 账户有可用余额。
  3. 打开软件 设置 → DeepSeek，粘贴完整 API Key。输入框会隐藏内容。
  4. 点 测试连接。显示“连接成功”后点 保存；连接测试检查账户接口可达性，不等于已经完成一次图像增强。
  5. 重新截图，按需要自动或手动增强。

软件使用 DeepSeek 官方 HTTPS 接口与支持图像的 deepseek-flash 模型；模型服务以官方当前提供的版本为准。图像能力说明见 DeepSeek 官方图像文档，费用见 官方定价。

自动增强：首页的“自动增强 · 可选”默认开启。已配置 Key 且本地识别质量低于阈值时才自动请求 AI；阈值在设置 → DeepSeek 中调整，默认 0.82。先显示本地结果，再处理增强。未配置 Key 时始终只有本地识别，不会自动申请密钥或扣费。

手动增强：截图后点击选区工具栏的 AI 增强。只要已保存 Key，即使首页自动增强关闭，也可手动增强。在“查看文字”里还可选择 AI 校正、恢复表格、优化公式、翻译、总结、解释。

本次是否增强：看选区工具栏的状态。成功、处理中、失败或取消会分别显示；只有成功返回并应用结果，才算本次已经增强。

自动增强关闭后不会自动上传截图；你主动点击 AI 功能时仍会上传本次选区图像和本地识别文字。敏感内容可不使用 AI。AI 结果可能出错，使用前请核对数字、姓名、公式等重要信息。

5. 后台运行与开机启动

双击程序会打开首页。关闭首页右上角的 × 后，程序仍在系统托盘运行，截图快捷键继续有效。

托盘图标可能在任务栏右侧的 ∧ 隐藏图标中。点击图标打开首页；右键可开始截图、打开设置、查看历史或退出。

开机自启默认开启。在设置 → 常规可关闭。开机启动且“启动后在后台运行”开启时只显示托盘，不主动弹首页。手动双击启动会显示首页。

应用、模型和运行数据放在 D 盘。自启功能仅在 Windows 实际“启动”文件夹创建 DeepPick AI.lnk；这个文件夹可能在 C 盘。程序不会安装系统服务、驱动或修改系统安全策略。Windows 自身产生的系统记录不属于程序数据目录。

6. 历史、导出与存储

历史记录保存最近 20 次识别文字。点击首页“历史记录”可查看、复制、删除所选或清空。在设置 → 常规可关闭后续保存；关闭保存不会自动删除已有记录。

历史记录不保存截图，但保存的文字可能包含个人信息。需要清除时请用历史页面的删除按钮。

在 设置 → 存储 可查看占用、修改缓存上限或点“清理缓存”。默认 cache 与 temp 合计上限为 128 MB，可调整为 32–4096 MB。

数据清理规则
temp 临时文件启动时清理，运行中清理存放超过 1 小时的文件
cache 缓存超过 7 天删除；与 temp 合计按上限清理
自动清理启动、每 5 分钟以及打开或保存设置时触发
logs 日志合计最多 50 MB，优先移除旧日志
history 历史最近 20 次，用户可删除
output 导出由用户管理，不自动删除

清理会跳过正在使用的文件和刚创建的临时文件，暂时超限时会后续重试。模型和程序组件是固定文件，不计入缓存上限，清理缓存不会删除它们。OCR 截图通过内存传输，不会连续保存成图片。

模型在后台保持就绪以保证响应。空闲后会回收多余工作内存；大图处理期间仍可能有短时内存峰值。准确占用取决于电脑、截图尺寸和运行状态，不应只按 EXE 文件大小判断内存。

8. 更新、分享与卸载

更新：先右键托盘 → 退出，再将新版完整包中的程序组件覆盖到 D:\DeepPickAI。保留自己原来的 config、history 和 output；不要删除加密配置密钥。覆盖时不要同时运行旧版。遇到权限或版本问题，先确认所有 DeepPick AI 进程已退出。

再次分享：转发原始“分享版.zip”。不要压缩自己使用过的安装目录给别人，其中可能包含个人密钥配置、历史和导出内容。

卸载：设置 → 常规取消“开机自启”并保存 → 托盘退出 → 删除桌面快捷方式 → 按需要保留导出文件后删除 D:\DeepPickAI 文件夹。没有系统组件卸载步骤。

9. 常见问题

下载后需要安装 Python 或模型吗？

不需要。分享包包含完整运行库和离线模型。必须先完整解压，再双击根目录 EXE；单独复制一个 EXE 无法运行。

电脑没有 D 盘怎么办？

当前版本明确要求 D 盘，不会自动改装到 C 盘，也不会替你分区。没有 D 盘的电脑暂时无法按本版本的安装方式使用。

找不到 EXE，或提示运行库、模型缺失？

检查是否完整解压、是否出现 D:\DeepPickAI\DeepPickAI 这样的双层目录，或只复制了 EXE。正确路径是 D:\DeepPickAI\DeepPickAI.exe。重新解压原始包可恢复程序组件；已有用户更新时先保留 config、history 和 output。

Windows 安全软件拦截或删除文件怎么办？

从原始分享包重新检查文件完整性，确认 Windows 10/11 x64、解压路径正确。根 EXE 和 Python DLL 保留官方运行时签名，应用源码没有独立发布签名；不同电脑的安全策略仍可能拦截。不要关闭系统安全功能，企业电脑请让管理员检查拦截记录。若仍无法启动，将系统版本和具体错误截图反馈给开发者，不需要提供密钥。

点 × 后为什么快捷键还能用？怎样彻底退出？

× 只隐藏首页。右键任务栏托盘中的 DeepPick AI 图标 → 退出。托盘图标通常藏在 ∧ 里。

开机后没有首页，是没启动吗？

默认开机后台启动，不弹首页。查看托盘图标，或直接试截图快捷键。希望开机显示首页，可在设置 → 常规取消“启动后在后台运行”，保留开机自启。

Ctrl + Space 没反应，或切换了输入法？

先从首页按钮测试截图。如果按钮可用，通常是快捷键占用。设置 → 快捷键更换组合并保存；程序会提示注册失败的情况。某些全屏游戏、远程桌面或安全桌面可能不接受普通桌面快捷键。

为什么框选后还没有马上出现可选文字？

点阵动画与“识别中”表示正在处理。首次启动时后台还需准备模型；大面积截图、密集文字或繁忙电脑也会更慢。程序启动后保持模型就绪；框选实际文字区域可以减少处理量。AI 增强还受网络和官方服务速度影响。

怎么判断本次有没有 AI 增强？

看选区工具栏状态。仅配置 Key、打开自动增强或连接测试成功，都不表示本次已经增强。低质量触发后或你手动点击后，成功状态才表明本次已增强；失败时仍可使用已有本地结果。

关闭自动增强后，还能手动 AI 吗？

可以。设置里保存有效 Key 后，工具栏“AI 增强”和结果页 AI 操作始终独立可用。关闭自动增强只禁止自动请求。

没有密钥能用吗？自动增强默认开着会扣费吗？

可以离线使用本地 OCR。未配置 Key 时不会请求 DeepSeek。填入 Key 后，自动增强和主动 AI 操作才可能消耗自己的 API 额度；关闭自动增强后，手动 AI 请求仍会计费。

Key 已填，但 AI 按钮仍不可用？

确认在设置中点了“保存”，而不是只测试连接或点了取消。重新截图后再试。不要用网页聊天登录密码代替 API Key。

“API Key 无效” / HTTP 401？

在 DeepSeek 控制台确认 Key 未撤销，重新复制完整 Key，在软件设置中保存。不要把 Key 发给别人或贴进反馈截图。

“余额不足” / HTTP 402？

检查 DeepSeek API 账户余额。网页版聊天可用不代表 API 账户还有额度；补足额度后重试，本地识别不受影响。

“请求过于频繁” / HTTP 429，或 HTTP 500 / 503？

429 表示请求速率超限，等待后减少连续请求；500 / 503 通常是官方服务故障或繁忙，稍后再试。官方说明见 DeepSeek 错误码。

连接失败、超时，或连接成功却图像增强失败？

检查是否能访问 DeepSeek 官方 API，网络、代理或企业防火墙是否允许连接。连接测试不提交图像，也不验证实际付费调用。确认账户支持当前图像模型、余额充足；400 类图像请求错误或图像模型暂不可用时，可先用本地结果并稍后更新软件。

OCR 漏字、识别错字、表格乱序怎么办？

先放大原页面，使字体清晰，再框选较小范围。避免选区切断字形。支持中文、英文及常见字符；其他文字、手写、小字或特殊字体不保证准确。配置 Key 后可手动校正、恢复表格或优化公式，也可在“查看文字”中直接编辑。

为什么图上字形没变，复制出来的文字却已校正？

选区保留原始截图，不重画 OCR 或 AI 字形，以避免重影。AI 校正更新的是识别内容；“查看文字”和复制结果显示校正后的文本。新增文字位置只能按模型结果估计，复杂场景请核对。

拖选没有选中、黄色高亮不准确怎么办？

先看工具栏是否仍在识别，等待完成后在明亮的文字区域拖动。不要从工具栏按钮开始拖。明显错位时重新截图，先从单个显示器的清晰区域尝试；多屏混合缩放和特殊应用请反馈屏幕缩放与具体场景。按 Ctrl + A 可选择本次全部识别文字。

部分视频、游戏或安全窗口截图是黑色？

受保护的视频、锁屏和 Windows 安全桌面可能禁止普通程序截取。先在普通网页或文档上尝试；程序不会绕过系统或应用的屏幕保护。其他普通窗口也异常时，可退出重启并反馈具体应用与显示器配置。

Ctrl + Enter 没有复制全部文字？

它只复制已经黄色高亮的文字。需要全部文字时先 Ctrl + A，或打开“查看文字” → 复制全部。确认选区仍打开、剪贴板没有被其他工具立即覆盖。

占内存，或清理后磁盘占用没有降很多？

离线模型保持预热，会有持续内存占用；大图处理后会回收工作内存，模型仍保留。固定运行库和模型并非垃圾缓存，清理不会删除它们。设置 → 存储只统计运行缓存和日志等数据；output 中的导出由你管理。若长期异常增长，可退出重启并反馈截图尺寸和日志。

清理缓存后为什么显示有文件使用中？

程序跳过正在使用的文件与刚创建的临时文件以保证识别正常。每 5 分钟会重试；必要时退出再重新启动。不要删除 app、models 或 config 来清理缓存。

换电脑能带走设置吗？

新电脑建议解压原始分享包并重新填 Key。加密配置有当前 Windows 用户访问权限，不承诺跨账户直接迁移。只需要保留输出时，复制 output 中的文本即可；不要把包含 vault.key 的 config 文件夹当作普通分享资料。

反馈时提供：Windows 版本、屏幕缩放比例、点击路径、错误文字和日志中相关时间段。尽量使用不含隐私的截图。日志位于 D:\DeepPickAI\logs；不要发送 API Key、config 文件夹或私人识别历史。

当前分享包已做离线启动与本地识别检查。真实 AI 调用需要你自己的有效 Key、网络和 API 额度；不同硬件、多屏混合缩放及企业安全策略仍需按实际环境确认。
