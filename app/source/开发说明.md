## 当前结构

- app/source：模块化源码、图标、依赖版本与传统冻结构建配置。
- app/runtime：正式嵌入式运行库。根 EXE 为未修改的官方签名 CPython GUI 运行时，仅重命名。
- app/licenses：第三方许可证、组件来源。
- app/development/venv：保留的当前开发依赖环境，不进入分享包。
- models：当前离线模型、字典及来源校验。正式 OCR 使用 PP-OCRv4 ONNX CPU 推理。
- app/source/tools/publish_release.py：只收录正式运行所需文件的分享包生成器。
- app/source/tools/make_guide.py：从根目录使用说明.md 生成离线 HTML 教程。

旧版备份、候选构建、试验运行库、临时图片和本次任务测试脚本已按用户 2026-10-07 的明确授权删除。验收结论与清理记录留在交付 outputs，保留当前可用于修改的源码、模型及开发环境。

## 生成发布包

修改正式源码后无需重新编译或改写签名 EXE。依赖或 Qt 版本改变时须先准备相匹配的正式运行库并实机验证，不能只覆盖 DLL。先从托盘退出，再更新组件。

```powershell
$env:TEMP = 'D:\DeepPickAI\temp'
$env:TMP = 'D:\DeepPickAI\temp'
$env:PYTHONDONTWRITEBYTECODE = '1'
& 'D:\DeepPickAI\app\development\venv\Scripts\python.exe' -B 'D:\DeepPickAI\app\source\tools\make_guide.py'
& 'D:\DeepPickAI\app\development\venv\Scripts\python.exe' -B 'D:\DeepPickAI\app\source\tools\publish_release.py' --output 'D:\DeepPickAI\output\releases'
```

发布器采用白名单，只收录 app/source 的运行源码、app/runtime、app/licenses、models 与必要根文件和教程。它不会收录个人 config、history、logs、cache、temp、output、开发环境或绑定本机的快捷方式。生成后会检查 ZIP CRC、逐文件 SHA-256、路径和私有目录为空，并提供发布清单与整体校验。

版本变更需同步 UI 关于信息、app/runtime/manifest.json、发布器 VERSION 和教程。当前官方运行时来源与校验见 app/runtime/manifest.json；DeepPickAI._pth 隔离模块路径，不使用系统或用户 site-packages。

## 启动及退出

直接双击 EXE，sitecustomize 启动正常初始化的 -m deeppick_entry 后退出短暂委托进程；常驻 GUI 与 OCR 两个进程。桌面、自启快捷方式直接使用 -B -m deeppick_entry，自启另加 --background。

维护退出：DeepPickAI.exe -B -m deeppick_entry --quit。不要直接给官方 Python 运行时传 --quit，也不要在 site 初始化内部执行 Qt 事件循环。正常 GUI 退出使用 SystemExit，保留 Qt 所属对象直到显式退出完成；禁止用 os._exit 跳过 PySide 的清理。

## 边界与验证重点

坐标以截图真实像素计，界面按实际 devicePixelRatio 映射。浮层显示原始截图，不重绘识别字形。AI 校正保留已有本地行的四边形；新增位置仍需核对。

模型保持就绪，三模型共享 ORT CPU arena，权重不随工作内存回收；每轮缩减 arena，闲置后小检测回收剩余 scratch。不要用卸载模型的方式交换内存与下一次响应速度。

自动增强必须开关开启、已配置 Key、质量触发；手动请求不受自动开关限制。连接测试不代替真实图像调用验证。服务不跟随带密钥的重定向，不接受任意自定义 API 地址。

配置使用 AES-256-GCM，settings.enc 与 vault.key 一起保存，ACL 为当前 SID 与 SYSTEM。避免输出 Key、解密后的配置、个人历史或完整 HTTP 请求。自动清理只处理运行缓存、临时文件与日志；不删除 config、history、output、模型或维护源码。

新增功能时验证离线启动、完全退出后双击、托盘后台、快捷键冲突、真实框选与复制、负坐标和混合 DPI、多段选择、AI 失败与旧请求隔离、缓存限额和目录链接。原生 QA 使用小窗口或后台生成图片，不反复弹出全屏彩色测试背景。

官方运行时保留其自身签名；应用源码没有独立发行签名。不要修改 Windows 智能应用控制或关闭安全软件以绕过拦截。真实付费 AI 与更多硬件环境需要单独验证，不能把本机验收当作全部用户环境保证。
